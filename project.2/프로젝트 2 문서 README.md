# 1. 자동화할 반복 업무
## 업무명

## 고객 등록 알림 자동화

## 업무 설명

- 기존에는 Google Sheets에 새로운 고객 정보를 입력하면 담당자가 직접 메일을 작성하여 알려야 했다.
- 이를 자동화하여 새로운 고객 정보가 등록되면 Gmail이 자동으로 알림 메일을 발송하도록 구성하였다.

# 2. 자동화 도구 선정
## 사용 도구

## Make

## 선정 이유

- Make는 시각적인 인터페이스를 제공하여 자동화 흐름을 쉽게 구성할 수 있다.
- 또한 Google Sheets와 Gmail을 무료 플랜에서도 쉽게 연동할 수 있으며, Filter와 Router 같은 기능도 제공하여 다양한 자동화를 구현하기 적합하다.

# 3. 워크플로우 설계
Google Sheets
      │
      ▼
새 행 추가
      │
      ▼
Gmail
      │
      ▼
자동 이메일 발송

# 4. 자동화 흐름 설명

① Google Sheets에 새로운 고객 정보를 입력한다.

↓

② Make가 새로운 행을 감지한다.

↓

③ Gmail이 자동으로 실행된다.

↓

④ 담당자에게 고객 등록 알림 메일을 전송한다.

# 5.Trigger

## Google Sheets - Watch New Rows

Google Sheets에 새로운 행이 추가되면 자동으로 워크플로우가 실행된다.

# 6.Filter
## 조건

금액 > 10000

조건을 만족하는 경우에만 이메일을 발송하도록 설정하였다.

이를 통해 불필요한 이메일 발송을 방지하였다.

# 7.Action
## Action 1

Gmail

새로운 고객 등록 안내 메일을 자동으로 발송하였다.

메일 내용에는 Google Sheets에서 입력한 고객 이름을 포함하도록 설정하였다.

# 8. 실행 과정
1. Google Sheets에 새로운 고객 정보를 입력한다.
2. Make가 새로운 행을 감지한다.
3. 금액이 10,000원보다 큰지 확인한다.
4. 조건을 만족하면 Gmail이 자동으로 실행된다.
5. 등록 안내 메일이 자동 발송된다.

 # 9. 실행 결과

실제로 Google Sheets에 새로운 고객 정보를 입력하였고,

Make가 자동으로 실행되어 Gmail을 통해 이메일이 정상적으로 발송되는 것을 확인하였다.



이를 통해 자동화 워크플로우가 정상적으로 동작함을 확인하였다.
